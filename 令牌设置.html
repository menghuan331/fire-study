令牌设置说明

学习台把进度存进你自己的私有仓库 fire-engineer-study。为此需要一个只能读写这一个仓库的 GitHub 令牌。一次设置，大约 5 分钟；令牌只存在你这台设备上。

  1. 打开 GitHub 的新建令牌页面

    登录 GitHub 后直接打开：

    新建细粒度令牌

    找不到的话：头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。

  2. 填名称和有效期

    • Token name：消考学习台（所有设备共用这一个）
    • Expiration：选 Custom，日期填 2027-12-31

  3. 只给这一个仓库

    • Repository access：选 Only select repositories
    • 下拉里只勾 menghuan331/fire-engineer-study

  4. 只给"内容读写"一项权限

    • Permissions → Repository permissions → Contents：选 Read and write
    • Metadata 会自动变成 Read-only，这是必需的，保持即可
    • 其他权限全部保持 No access

  5. 生成并复制

    点最下面的 Generate token，复制以 github_pat_ 开头的那串字符。它只显示这一次，关掉页面就看不到了。

  6. 粘贴进学习台

    • 打开学习台，点右上角的状态字（显示"未连接 GitHub"）进入设置
    • 把令牌粘贴进输入框，保存
    • 点 测试连接，看到"连接成功，可读写"就好了
    • 再点 立即同步，状态字变成"已同步 HH:mm"

  7. 添加到主屏幕

    在 iPad 的 Safari 里点分享按钮 → 添加到主屏幕。以后从主屏幕图标打开，进度不会被 Safari 清掉。

  8. 其他设备：一点就填好

    进度在所有设备之间自动同步，不用复制。每台新设备只要填一次令牌：

    • iPhone、Mac 等苹果设备：第 6 步保存令牌时，Safari 会问要不要存进钥匙串，选"存储"。之后在别的苹果设备上打开设置页，点令牌框会出现保存的令牌，点一下就填好，再点"立即同步"。
    • 其他电脑：把同一个令牌手动粘贴一次即可，一个令牌可以多台设备共用。

安全须知

  • 令牌等于这个仓库的钥匙，不要发给任何人，也不要贴到聊天里。
  • 它只能读写 fire-engineer-study 这一个仓库，碰不到你的其他仓库和账号设置。
  • 设备丢了：到 GitHub 的 Fine-grained tokens 页面删掉这个令牌，照这页重新生成一个，在还在用的设备上换成新的。
  • 到期前 GitHub 会发邮件提醒，照这页再生成一个替换即可。
